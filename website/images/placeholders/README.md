# Website image placeholders

These are **requested assets** for palmengine.org. Drop files into `website/images/screenshots/` and wire them in `index.html` (replace placeholder cards).

| Suggested file | What to capture | Aspect |
|----------------|-----------------|--------|
| `palm-vitality-top.webp` | Living-kernel vitality / Inspect top — CLI or TUI showing seat walk / system “top” under load or idle | ~16:9, dark UI |
| `palm-assist-mcp.webp` | Coding agent or MCP Inspector using `palm_assist` (menu, flow run, or waiting question) | ~16:9 |
| `palm-benchmark.webp` *(optional)* | `palm benchmark` or inspect benchmark output — capacity / work_cycle story | ~16:9 |
| `palm-tree-topology.webp` *(optional)* | Diagram or UI of multi-place topology if we ever prefer a photo over the SVG | ~16:9 |
